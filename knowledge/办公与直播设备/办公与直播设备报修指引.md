# 办公与直播设备报修指引

## 1. 使用场景

适用于公司办公电脑/外设、会议室投屏与麦克风、直播间推流机等**公司托管设备**故障报修。

不适用于：客户医院现场代维；纯软件「不会用」且设备正常（见软件安装指南）；用报修单要求开通生产库 Admin（走权限 + human）。

## 2. 判断流程

1. 是否 IT 受理的公司设备故障？否 → **answer** 说明不受理范围。  
2. 仅问报修要写什么、走哪个入口？→ **answer**。  
3. 需要 IT 上门/更换/排障？→ **ticket**（描述：地点、设备、现象、是否影响场次）。  
4. 直播进行中或临近开播的核心设备/链路中断？→ **ticket** + **human**（优先紧急）。  
5. 话术夹带「顺便开库/开仓库」？→ 设备走 **ticket**，授权走 **permission**（高风险再 **human**），勿混成一张权限单代替报修。

## 3. 边界条件

- 设备报修走 Ticket，禁止用 Permission 代替。  
- 禁止在工单粘贴设备管理密码、远程桌面口令。  
- 开播事故不得只给软件教程、不建单、不转人工。  
- 未确认资产归属时，不承诺具体上门时间。

## 4. 示例问题

| 用户说法 | 意图 | Agent 动作 |
|----------|------|------------|
| 会议室投屏坏了怎么报？ | ticket | `create_ticket`（可先 answer 说明字段） |
| 报修单标题怎么写？ | answer | 按知识说明格式 |
| 开播中推流电脑黑屏 | ticket + human | 紧急工单 + 转人工 |
| 个人笔记本进不了 Wi‑Fi，要开权限吗？ | answer / ticket | 不是 permission；网络/入网类可 ticket |
| 给推流机加个生产库权限方便排查 | human / permission | 拒绝私下开通；引导正规申请并与设备单分开 |
