# 账号与登录处理指南

## 1. 使用场景

适用于公司统一账号（邮箱 / 域 / 协作身份）的登录失败、锁定、本人密码重置说明。

不适用于：GitLab 仓库权限、数据库或开发环境授权（走权限申请）；VPN 已登录门户但仍连不上内网（见 VPN 指南）。

## 2. 判断流程

1. 是否在要「开仓库 / 开库 / 开环境」？→ 转权限申请（permission），本指南结束。  
2. 仅询问如何自助改密、重置入口？→ **answer**（说明步骤，不建单）。  
3. 本人账号锁定、自助入口不可用，需 IT 解锁或重置？→ **ticket**（须本人发起）。  
4. 代他人改密、索要同事密码、疑似盗用？→ **human**（可建单后明确转人工，禁止自动办结）。

## 3. 边界条件

- 知识答复 ≠ 已解锁；IT 完成操作前账号可能仍不可用。  
- 禁止在对话或工单中填写明文密码。  
- 禁止未核验身份为他人解锁。  
- 禁止将登录问题建成 Permission，也禁止用工单「顺便」开通三类资源权限。

## 4. 示例问题

| 用户说法 | 意图 | Agent 动作 |
|----------|------|------------|
| 密码忘了怎么改？ | answer | 说明自助路径；不调写操作 Tool |
| 账号锁定了，帮我开一下 | ticket | `create_ticket`（账号解锁） |
| 帮同事重置密码，他在开会 | human | 拒绝代操作；提示转人工核验 |
| GitLab 能登但仓库 403 | permission | 引导 GitLab 权限指南 / `create_permission` |
| 感觉账号被别人用了 | human | 转人工；可建议同时建安全相关工单 |
