# 标准软件安装与例外申请指南

## 1. 使用场景

适用于公司标准办公/协作/直播相关**客户端安装**说明，以及需 IT 代装或例外软件的工单。

不适用于：开发/预发**环境账号或角色**（`DEV_ENV` 权限申请）；仓库或数据库授权；设备硬件损坏（设备报修）。

标准软件（可先自助说明，清单以 IT 公布为准）：办公套件、公司协作客户端、公司指定直播推流/会议客户端。

## 2. 判断流程

1. 询问是否在标准清单、如何自助安装？→ **answer**。  
2. 本机无权限需 IT 代装，或清单外但有业务必要？→ **ticket**（写明软件名与用途）。  
3. 破解版、未批准远程控制、盗版序列号等？→ **answer** 拒绝；已安装需处置 → **human**。  
4. 「装完 IDE / Docker 再开预发环境」？→ 安装按上序；环境账号另走 **permission**（`DEV_ENV`），勿用一张工单代替权限。

## 3. 边界条件

- 禁止指导安装破解或未授权商业软件。  
- 禁止用 `create_permission` 表达「装软件」。  
- 禁止在工单粘贴许可证密钥全文。  
- 个人电脑装机默认不在 IT 代装范围（影响公司入网除外，可 ticket 评估）。

## 4. 示例问题

| 用户说法 | 意图 | Agent 动作 |
|----------|------|------------|
| 公司标准办公软件怎么装？ | answer | 按知识说明 |
| 电脑没权限，帮装直播客户端 | ticket | `create_ticket` |
| 能装某某破解设计软件吗？ | answer | 拒绝 |
| 装完 Docker 要预发环境账号 | permission | `create_permission`（DEV_ENV）；安装本身另判 |
| 把安装包和序列号发群里 | human | 拒绝并升级人工 |
